## Experience

### 1/10 자율주행 레이스카 — 팀장 · 하드웨어 및 소프트웨어 총괄
`2026.01 – 2026.03` · 제5회 국제 대학생 EV 자율주행 경진대회 (1/10 Autonomous Mobility Racing) · **최우수상**
[저장소 보기 →](https://github.com/GeonHoong/1_10-autonomous-race)

- Autodesk Inventor·Fusion 360으로 1/10 스케일 RC카 섀시를 설계하고, 대회 규정상 허용된 기본 베이스를 제외한 전 부품을 직접 제작
- 자율주행/조이스틱 명령을 0.6초 타임아웃 기반으로 중재하는 **MUX 통합 제어 노드**를 설계, 50Hz 주기로 단일 명령을 발행하는 페일세이프 구조 구현
- **Raspberry Pi 5(메인) · OpenCR(서브)** 간 micro-ROS 기반 실시간 모터 제어 아키텍처를 구축해 인지·판단 계층과 액추에이터 구동 계층을 분리
- 차선 곡률·주행 속도에 따라 Pure Pursuit Lookahead 거리와 LiDAR 인식 ROI(사각형 ↔ 부채꼴)를 동적으로 연동시키는 알고리즘을 설계, TTC 기반 충돌 회피로 오인식·오차를 감소
- 서로 다른 주기(Hz)로 발행되는 카메라·LiDAR·OpenCR·Raspberry Pi 토픽 간 병목 현상을 줄이는 방향으로 전체 제어 파이프라인 설계
- **결과**: 대회 최우수상 수상
